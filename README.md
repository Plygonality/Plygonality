# Plygon

Technical artist focused on procedural 3D, environment art, and DCC tooling. Currently studying Game Graphics Production at HOWEST DAE.

Mostly working with Blender, Houdini, Unreal Engine, and Python.

### Projects

**[Plygon MCP](https://github.com/Plygonality/Plygon-mcp)**  
Local MCP tools for working with Blender and Houdini through AI agents. Supports scene editing, inspection, and viewport capture.

**[NodeBridge](https://github.com/Plygonality/NodeBridge)**  
A work-in-progress tool for converting procedural node setups between Blender, Houdini, and Unreal Engine.
